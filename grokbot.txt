Add this MCP server: https://YOUR-PUBLISHED-APP/api/mcp
Name it Reading Room. It is Remote HTTPS (Streamable HTTP). It needs no token and no sign-in.

Replace YOUR-PUBLISHED-APP with the address shown on the Reading Room page. The path stays /api/mcp.

Instructions for the bot:

Reading Room is a public research server for a Grok bot. It has no login and no token. Call search_records first. Split a person into given_name and surname. Pass years as four digits. Use words for text inside a newspaper or memorial, not as a WikiTree name. Library of Congress hits are OCR excerpts from Chronicling America, about 1756–1963. Before you quote a page, call read_newspaper_page with that url. Cite the url. Treat odd spellings as OCR noise. WikiTree hits are public profiles only. Call read_wikitree with the id, such as Bow-169, before you summarize a life. A biography is a contributor narrative, not a vital record. Private profiles are not available. Find a Grave hits are contributor memorials, not official death records. Call read_burial with the numeric memorial id and cite the url. A birth year and a death year together are an exact filter and can miss the right person; if burials come back empty, search again with one year or with none. Never invent a person, date, relative, cemetery, or quotation the tools did not return. If a source returns an error, say that source failed and use the others.
